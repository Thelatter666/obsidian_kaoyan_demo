# 考研知识库

> 这个库只干一件事：**接住你随手抛来的问题，把里面的考点、生词、短语抽出来沉淀成错题本。**
> 不管课程进度、不排大纲——只记你真正问过的东西。

> **独立声明**：这个库与外部课程系统（如网课、排期等）**互不相通**。
> 本库不读外部数据，外部也不读本库；同一个知识点两边各记一份，**不必同步、不必对账、不必互引**。
> 区别在于问的问题不同：这边问「**这个问题我当时是怎么错的**」，那边问「**这门课我学到哪了**」。

**为什么流水账按科目拆文件**

数学和英语是两个独立的辅导会话，同时在跑。**两个 agent 写同一个文件会互相覆盖，而且不报错**——后写的把先写的整段盖掉，数据就这么没了。
按 `日期-科目.md` 分文件之后，各写各的，物理上不可能撞。索引同理：数学索引归数学会话，英语索引归英语会话。

> 附件同理，命名带上科目：`YYYY-MM-DD-英语二-<来源>-<内容>.<ext>`。

**为什么要分两层**

- 流水账只增不改 → 永不丢信息。原题和完整解答都在，半年后能看你当时到底卡在哪。
- 索引是蒸馏过的 → 能直接拿来复习。同一个词问三次，索引里只有一条，但能点回三次的原始上下文。

只做索引会丢细节，只做流水账没法复习。

## 流程

**你**：把问题发给辅导老师。文字、截图、拍照都行——草稿纸拍张照给老师，老师直接读你的解题过程。不用管格式，不用说要记什么。

**辅导老师**：先反问一句（见下）→ 解答 → 抽考点/生词/短语 → 写进当天流水账 → 更新对应索引与闪记本。

**你自己翻**：在 Obsidian 里打开 `考研总看板.md`，或者点进 `索引/` 下的文件。每条带 `[[YYYY-MM-DD-科目]]` 形式的链接，点回去看当时的原题。

## 错因标签（四个档，每条必打）

决定你提分的不是"哪个知识点错了"，是"**为什么**错"。两个维度交叉才有用：

| 标签 | 含义 | 该干什么 |
|---|---|---|
| `概念不清` | 定义/定理没吃透 | 回头补理论，**这类最值钱** |
| `思路没想到` | 会做，但没想到用这招 | 刷同类型，把触发条件刻进脑子 |
| `计算失误` | 方法对了，算错 | 不是你不会，是不稳 → 掐表练手算 |
| `看错抄错` | 读题、誊写出的错 | 考场纪律问题，低级但致命 |

## 先反问一句

辅导老师解答前会先问：**"你是不知道怎么下手，还是知道方法但算不出来？"**

- 不知道怎么下手 → 讲**怎么想到**（这题的触发条件、该调出哪条路）
- 知道方法算不出来 → 讲**怎么算对**（步骤拆解、易错点）

两者讲的东西完全不同。嫌烦就直接发题，老师会按纯解答模式走。
